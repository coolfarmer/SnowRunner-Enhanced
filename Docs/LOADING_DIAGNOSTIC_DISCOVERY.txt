ENGLISH
Fifth experimental build. Retains the fourth build's normal signature discovery,
validation, startup timing, compilation of the empty native callback and periodic
reporting. The callback is NOT attached. No ENHANCED menu or optional enhancements.
Existing configuration and preferences are preserved.

Report: SnowRunnerEnhanced.loading-diagnostic-discovery-only.status.json beside
SnowRunner.exe. Check the current processId/timeUtc and buildMode equal to
loading-diagnostic-discovery-only. components.settings_menu must be disabled,
with probeInitialized=true, interception.mode=discovery-only, nativeHooks=0 and
filters=0. probeInitialized=true confirms discovery/validation reached the probe;
missing signatures must leave it uninitialized, making the timing inconclusive.

Restart fully and time Continue -> playable using the same save state. Previous
approximate user timings: no hooks/no discovery 22 s; menu 77 s; grouped menu
66 s; empty interception 62 s. This control isolates attaching the empty callback.
It is not a fix. Repeat timings before attributing small differences to code.

Close the game before replacing only SnowRunnerEnhanced.asi. Keep its previous
version outside game folders, and retain loaders, other mods, JSON preferences
and the comparison save. Never leave duplicate Enhanced ASIs in game folders.
Restore the original ASI after testing, with the game closed. No installer or
loader is included. Normal gameplay may update the save; keep a separate backup.
Automated tests do not establish real-game performance.
