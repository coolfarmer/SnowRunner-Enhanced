ENGLISH
Fourth experimental build. Same core signature discovery, validation and VM
entry as the menu-only/grouped tests. One native onEnter callback immediately
returns: no VM reads, filters, counters, menu callbacks or JavaScript transitions.
All enhancements and the ENHANCED tab are disabled. Periodic reporting remains.

Report: SnowRunnerEnhanced.loading-diagnostic-empty-hook.status.json beside
SnowRunner.exe. Check current processId/timeUtc and buildMode equal to
loading-diagnostic-empty-hook. components.settings_menu must be disabled, with
interception.mode=empty, nativeHooks=1 and filters=0. Missing signatures leave
the probe unattached. This test is not valid unless nativeHooks equals 1.

Restart the game fully and time Continue -> playable on the same save.
Previous approximate user measurements: no hooks 22 s, menu only 77 s,
grouped menu 66 s. This test separates callback work from the remaining
interception/discovery cost; it does not measure discovery alone. Results need
repeated comparisons before attributing small differences to a code change.

Close the game before replacing only SnowRunnerEnhanced.asi. Keep the previous
ASI outside game folders, and preserve loaders, other mods, configuration and
preferences. Never keep multiple Enhanced ASIs in the game's folders. Restore
the original ASI after testing, with the game closed. No installer/loader is
included. Normal gameplay may save changes; retain a separate comparison save.
Automated validation does not establish real-game loading performance.
